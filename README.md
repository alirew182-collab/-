# 🤖 Нейрон: Академия

Android-приложение для последовательного обучения **алгебре, физике и химии с 9 по 11 класс** с ИИ-репетитором «Нейрон» и геймификацией.

**Kotlin · Jetpack Compose (Material 3) · MVVM · Room · Ktor · WorkManager · KaTeX (офлайн) · minSdk 26**

## Экраны
1. Онбординг со знакомством с Нейроном
2. Карта мира: регионы 9/10/11 классов, замки, прогресс, уровень, XP, 💎, 🔥
3. Мир предмета — карта-путь тем в стиле Duolingo + узел босса
4. Тема: теория / примеры / практика / тест / интересный факт, «Объясни иначе», «Зачем это в жизни?», напоминание прошлых тем
5. Итоговый экзамен — битва с боссом (HP босса, сердечки игрока)
6. Чат с ИИ-репетитором (формулы через KaTeX)
7. Мини-игры: Блиц (60 с), Дуэль с ИИ, симуляции (парабола, бросок под углом, смешивание веществ)
8. Ежедневные задания, задача дня, серия и заморозка
9. Достижения и коллекция карточек
10. Магазин (скины, темы, подсказки, заморозки)
11. Профиль: шкала 9 → 10 → 11, графики за неделю/месяц, персональные итоги
12. Настройки: API-ключи, режим выбора ключа, тема, звук, уведомления, порог, режим учителя (PIN)

## Правила прохождения
* Старт — 9 класс. Класс N+1 открывается, когда в классе N по **каждому** предмету пройдено ≥ 80 % тем (порог настраивается) и побеждён босс.
* Тема засчитывается при тесте ≥ 70 %; следующая тема открывается после неё.
* Закрытые элементы видны с замком и подсказкой, что нужно сделать.
* «Режим учителя» (PIN) открывает всё для повторения.

## Дизайн
* Палитра «бумага и чернила»: тёплый светлый фон, графитовая тёмная тема, один акцентный цвет, без градиентов и неона.
* Шрифты: **Unbounded** (заголовки и цифры) и **Onest** (текст) — оба с кириллицей, лицензия OFL, лежат в `res/font`.
* Маскот «Нейрон» нарисован векторно (`ui/components/Mascot.kt`): моргает, у каждого скина свой аксессуар.
* Иконки Material Symbols вместо эмодзи в интерфейсе.

## Виджеты рабочего стола (Jetpack Glance)
| Виджет | Размер | Что показывает |
|---|---|---|
| Прогресс | 4×2 | уровень, XP, серия, кристаллы, задания; в высоком варианте — «Продолжить тему» |
| Задача дня | 4×2 | текст задачи дня и статус |
| Серия дней | 2×2 | число дней подряд и отметка за сегодня |
| Быстрый старт | 4×1 | продолжить тему, блиц, чат |

Нажатие на виджет открывает нужный экран. Виджеты обновляются автоматически при изменении прогресса и раз в 30 минут.

## ИИ и ключи
* Провайдеры (30): Anthropic (Claude), OpenAI, Google Gemini, OpenRouter, DeepSeek, xAI (Grok), Mistral, Groq, Cerebras, Together, Fireworks, Perplexity, Cohere, AI21, DeepInfra, Hugging Face, NVIDIA NIM, SambaNova, Novita, Hyperbolic, Alibaba Qwen, Moonshot (Kimi), Zhipu (GLM), MiniMax, YandexGPT, GigaChat (Сбер), Azure OpenAI, Ollama и LM Studio (локально), любой OpenAI-совместимый сервер.
* Для ключа: название, провайдер, модель (список или вручную), base URL, вкл/выкл, приоритет.
* Режимы: по приоритету, по кругу (round-robin), вручную для каждой функции.
* Fallback: при 429/401/403/5xx/таймауте/ошибке сети запрос сразу уходит на следующий ключ.
* Статистика по ключам: запросы, ошибки, время последнего использования, последняя ошибка.
* Ключи не хардкодятся: хранятся в EncryptedSharedPreferences, экспорт — в файл, зашифрованный паролем.

Без ключа работают вся теория, примеры, практика, тесты, боссы, блиц, дуэль (с симулированным соперником) и симуляции.

## Сборка APK

### Android Studio
1. Установите Android Studio (Ladybug или новее) с Android SDK 34.
2. `File → Open` → выберите папку проекта. Дождитесь синхронизации Gradle (JDK 17).
3. `Build → Build App Bundle(s) / APK(s) → Build APK(s)`.
4. Готовый файл: `app/build/outputs/apk/debug/app-debug.apk` (или `release/app-release.apk` для `assembleRelease`).
5. Для публикации создайте свой ключ подписи: `Build → Generate Signed App Bundle / APK` и замените `signingConfig` в `app/build.gradle.kts`.

### Командная строка
```bash
./gradlew :app:assembleRelease     # APK: app/build/outputs/apk/release/app-release.apk
./gradlew :gamification:test       # юнит-тесты модуля геймификации
```

### GitHub Actions
Workflow `.github/workflows/build-apk.yml` собирает APK при каждом пуше и кладёт его в артефакты сборки и в `dist/NeuronAcademy.apk`.
