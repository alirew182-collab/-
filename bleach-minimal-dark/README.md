# Bleach Minimal Dark — тема для Millennium (Steam)

Тёмный минимализм в стиле аниме **Bleach**: почти чёрные плоские панели (косоде
шинигами), белые тонкие разделители и заголовки (хаори капитана), мягкое
reiatsu-свечение, быстрые shunpo-анимации и абстрактные мазки японской туши.
Без персонажей, логотипов и символики аниме, только стиль.

## Что нового в 1.1 (почему 1.0 «ничего не делала»)

В версии 1.0 главное окно почти не менялось. Классы библиотеки Steam хэшированы
(вида `_2-O4ZG0KrnSrzISHBKctFQ`), и тема их не знала. Теперь:

- **Перекраска всего клиента.** `generated/steam-palette.css` собран из
  настоящих стилей Steam (client 1794536281): около 3800 правил, где
  тёмно-синие фоны, серый текст и синий акцент Steam заменены на переменные темы.
  Это библиотека, страница игры, список игр, друзья, чат, настройки, меню и диалоги.
- **Bleach-акценты** (`generated/steam-accents.css`): выбранная игра выделена
  оттенком акцента и «полосой-клинком», кнопка «Играть» залита акцентом,
  в верхней навигации белые активные вкладки.
- **Установщик** `install.bat`: сам находит Steam через реестр и кладёт тему в
  правильную папку. Это решает частую проблему вложенной папки после распаковки.
- **Генератор** `tools/build_steam_palette.py`: после обновления Steam тема
  пересобирается одной командой (см. ниже).

## Пресеты акцента

| Пресет | Акцент | Свечение | Характер |
|---|---|---|---|
| **Getsuga** (по умолчанию) | алый `#c1121f` | алое | чёрный + алый |
| **Reiatsu** | голубой `#4cc9f0` | голубое | духовное давление |
| **Hollow** | костяной `#e9e4d8` + красный | красное | заголовки цвета кости, красные кнопки |
| **Quincy** | бело-голубой `#cfe8ff` | холодное голубое | холодный, разделители с голубым оттенком |
| **Свой** | из редактора цветов | из редактора цветов | любые ваши цвета |

Контраст (WCAG): основной текст 16.5:1, вторичный 7.2:1 и выше, «тихий» 4.5:1 и выше.
Акцентный текст во всех пресетах не ниже 5.2:1, белый текст Steam на акцентных
кнопках не ниже 5.7:1. Это выше уровня AA (4.5:1).

## Эффекты (каждый выключается)

- **Reiatsu-свечение**: мягкая аура цвета пресета на hover у кнопок (включая «Играть»),
  на активных вкладках и выбранной игре.
- **Shunpo-анимация**: при наведении на обложку игры резкий сдвиг с полупрозрачным
  «остаточным образом», затем обложка встаёт чуть выше. Длительность задаётся
  ползунком 120–180 мс. При системной настройке «уменьшить движение» анимация отключается сама.
- **Мазки туши**: вместо прямых линий под заголовками, в меню и над подвалом магазина
  абстрактный штрих кисти (SVG-маска без текста).
- **Шрифт заголовков**: Cinzel или Shippori Mincho с острыми «клинковыми» засечками
  (Google Fonts, OFL). Кириллица подставляется из Cormorant SC и Cormorant.
- **Фоновое изображение**: ваша картинка, ползунки затемнения (40–95 %) и размытия (0–24 px).

## Установка (Windows)

Нужен установленный [Millennium](https://steambrew.app) версии 3.x
(проверено по исходникам v3.6.3).

1. Распакуйте архив куда угодно, например на рабочий стол.
2. Откройте папку `bleach-minimal-dark` и запустите **`install.bat`**. Он:
   - находит папку Steam через реестр (или спросит путь);
   - копирует тему в `<Steam>\millennium\themes\bleach-minimal-dark\`, а если есть
     старая папка `steamui\skins`, то и туда;
   - удаляет лишнюю вложенную папку, если она осталась от ручной распаковки.
3. **Полностью закройте Steam** (Steam → Выход, не просто крестик) и откройте снова.
4. Millennium → **Темы** → выберите **Bleach Minimal Dark**. Если Millennium
   попросит перезагрузить Steam, согласитесь.

### Вручную

Скопируйте папку так, чтобы получилось
`<Steam>\millennium\themes\bleach-minimal-dark\skin.json`.
Обычно это `C:\Program Files (x86)\Steam\millennium\themes\…`.

⚠️ Самая частая ошибка: при «Извлечь всё» Windows создаёт папку внутри папки,
`…\themes\bleach-minimal-dark\bleach-minimal-dark\skin.json`. Millennium такую тему
не видит. `skin.json` должен лежать **сразу** в `bleach-minimal-dark`.

## Не работает? Проверьте по порядку

1. **Темы нет в списке Millennium.** Проверьте путь до `skin.json` (см. выше) или
   просто запустите `install.bat`.
2. **Тема выбрана, но ничего не изменилось.** Полностью перезапустите Steam:
   Millennium читает настройки темы при запуске.
3. **Ничего не меняется даже после перезапуска.** В настройках Millennium, в общем
   разделе, в группе «Темы», должен быть включён переключатель
   **«Разрешить внедрение CSS»** (англ. *Allow StyleSheet insertions*). Без него
   Millennium не подключает CSS ни одной темы. После включения перезапустите Steam.
4. **Часть интерфейса снова синяя после обновления Steam.** Valve поменяла классы.
   Пересоберите тему (нужен Python 3.8+, сторонние библиотеки не требуются):
   ```
   python tools\build_steam_palette.py
   ```
   Скрипт скачает стили текущей версии Steam с официального CDN Valve
   (`client-update.steamstatic.com`) и перезапишет папку `generated\`.
   Можно взять файлы и из своей установки:
   `python tools\build_steam_palette.py --steamui "C:\Program Files (x86)\Steam\steamui"`.

## Что тема меняет

| Окно | Как распознаётся (`MatchRegexString`) | Файлы |
|---|---|---|
| Библиотека, страница игры | `^Steam$` | `base/variables.css`, `generated/*`, `base/global.css`, `windows/library.css` |
| Друзья и чат | `.friendsui-container` | … + `windows/friends.css` |
| Настройки и диалоги | `.ModalDialogPopup` | … + `windows/settings.css` |
| Контекстные меню | `Menu$`, `Supernav$` | … + `windows/menus.css` |
| Магазин | `https://store\.steampowered\.com/.*` | `base/variables.css`, `webkit/store.css` |

**Big Picture не затрагивается**: `UseDefaultPatches` выключен, ни один патч или
эффект не нацелен на окна Big Picture, а генератор пропускает правила
`.GamepadMode` и `.BasicUI`.

## Как устроены цвета

- **`colors.css` (RootColors)** — все цвета темы. Каждый можно поменять в редакторе
  цветов Millennium, без правки файлов.
- **`presets/*.css`** только переназначают `--bleach-accent`, `--bleach-glow`,
  `--bleach-accent-fill` и т.д. на нужную палитру.
- **`generated/steam-palette.css`** — перекраска Steam. Фоны Steam переходят в
  `--bleach-bg` / `--bleach-surface*`, текст в `--bleach-text*`, синий акцент в
  `--bleach-accent*`, зелёная кнопка «Играть» в `--bleach-accent-fill`.
  Статусные цвета (зелёный «в игре», жёлтый, красный) не меняются, но тоже идут
  через переменные из `generated/steam-colors.css`.
- В CSS-правилах темы нет ни одного цвета, записанного значением. Значения есть
  только в `colors.css` и в автоматически извлечённом `generated/steam-colors.css`.

## Свой фон

1. Положите картинку в `assets/background.jpg` (рядом с `assets/README.md`).
2. В настройках темы на вкладке **Фон** выберите «Клиент», «Клиент и друзья» или
   «Клиент, друзья и магазин».
3. Подберите **Затемнение** (больше — текст читается лучше; 75–85 % хорошо подходит
   для светлых обоев) и **Размытие**.
4. Другое имя или формат файла (`.png`, `.webp`) указывается в строке
   `--bleach-bg-image` в `effects/background.css`.

## Как это проверялось и что не проверено

Проверено:
- `skin.json` сверен с исходниками Millennium v3.6.3: загрузка тем, Patches,
  Conditions, ползунки, RootColors и внедрение CSS в магазин.
- `colors.css` пропущен через копию парсера RootColors Millennium: все цвета
  распознаются, у каждого есть имя и описание.
- Макет из **настоящих классов Steam** с **настоящими** `sp.css`/`library.css`
  отрисован в Chromium без темы и с темой в порядке подключения Millennium:
  список игр, выбранная игра, заголовки разделов, кнопка «Играть», друзья —
  во всех пресетах; эффекты, фон и shunpo тоже.

**Не проверено:** тема не запускалась в живом клиенте Steam (здесь нет Windows и
вашего аккаунта Steam), а `install.bat` не выполнялся. Если что-то выглядит не
так, пришлите скриншот: перекраска управляется таблицей в генераторе, и её легко
подправить.

```
├── windows/                    library · friends · settings · menus
├── webkit/store.css            магазин
├── presets/                    getsuga · reiatsu · hollow · quincy · custom
├── effects/                    reiatsu-glow · shunpo · ink-strokes · background
├── fonts/                      blade-cinzel · blade-shippori
├── tools/                      build_steam_palette.py + templates/
├── assets/                     сюда кладётся ваш background.jpg

```

## Чек-лист

**Включить тему**
- [ ] Millennium 3.x установлен, Steam запускается с ним.
- [ ] Запущен `install.bat` (или `skin.json` лежит в `<Steam>\millennium\themes\bleach-minimal-dark\`).
- [ ] Steam полностью перезапущен → Millennium → **Темы** → выбрана **Bleach Minimal Dark**.

**Переключить пресет**
- [ ] Millennium → Темы → Bleach Minimal Dark → настройки темы → вкладка **Пресет**.
- [ ] «Пресет акцента»: Getsuga / Reiatsu / Hollow / Quincy / Свой.
- [ ] Для «Своего»: откройте редактор цветов темы и поменяйте цвета «Свой · …».
- [ ] Если окно не перекрасилось, перезапустите Steam.

**Добавить свой фон**
- [ ] Картинка лежит в `assets/background.jpg`.
- [ ] Вкладка **Фон** → «Фоновое изображение» не «Выкл».
- [ ] Затемнение и размытие подобраны так, чтобы текст читался.

**После обновления Steam**
- [ ] Если интерфейс снова синий: `python tools\build_steam_palette.py`, затем `install.bat`.
