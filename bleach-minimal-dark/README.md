# Bleach Minimal Dark — тема для Millennium (Steam)

Тёмный минимализм в стиле аниме **Bleach**: почти чёрные плоские панели (косоде
шинигами), белые тонкие разделители и заголовки (хаори капитана), акцентный
«клинок» у выбранных элементов, мягкое reiatsu-свечение, shunpo-анимации и
абстрактные мазки японской туши. Без персонажей, логотипов и символики аниме,
только стиль.

## Версия 2.0: тема переписана с нуля

Версия 1.x перекрашивала Steam автоматически, «в лоб»: полмегабайта CSS в
каждом окне (даже в каждом контекстном меню), без продуманного дизайна. Для 2.0
я изучил устройство популярных тем для Millennium: **Adwaita for Steam**,
**Zehn**, **Minimal Dark**, **Simply Dark**, **Fluenty**, **SpaceTheme**,
**steam-leimu** и других. Тема перестроена так же, как лучшие из них:

- **Ручной CSS по областям интерфейса**: рамка окна и навигация, левая колонка
  со списком игр, главная с полками и карточками, страница игры, друзья, чат,
  настройки, меню, диалоги, элементы управления, магазин.
- **Точные классы Steam.** Каждый хэш-класс подписан читаемым именем и
  автоматически сверен с CSS текущего клиента (282 из 282 найдены):
  `python tools/check_classes.py`.
- **Единый дизайн.** Выделение везде одинаковое: тёмный оттенок акцента и
  «клинок» слева (список игр, меню, настройки, вкладки).
- **Лёгкие окна.** Меню получает 10 КБ CSS вместо 544 КБ; эффекты анимируют
  только `translate`, `opacity` и тени; тяжёлые селекторы `:has()` по картинкам убраны.

### Замеры производительности

Тяжёлый макет главного окна (400 строк списка игр, 200 карточек) с настоящим
CSS Steam (client 1794536281), Chromium, медиана из трёх прогонов:

| | Пересчёт стилей | Раскладка | 60 циклов «прокрутка + наведение» |
|---|---|---|---|
| Steam без темы | 38.6 мс | 25.1 мс | 242 мс |
| Тема 1.1 | 63.2 мс | 35.8 мс | 401 мс (+66 %) |
| **Тема 2.0** | **39.9 мс** | **28.0 мс** | **275 мс (+13 %)** |

Вес CSS на окно: главное окно 308 КБ (было 552), друзья 292 (было 554),
диалоги 287 (было 551), **меню 10 КБ (было 544)**.

## Эффекты (каждый выключается в настройках темы)

- **Reiatsu-свечение** — аура цвета пресета на кнопках, «Играть», активной вкладке,
  выбранной игре и разделе настроек.
- **Shunpo-анимация** — при наведении обложка резко смещается с «остаточным
  образом» и встаёт чуть выше (120–180 мс, ползунок). Отключается сама при
  системной настройке «уменьшить движение».
- **Мазки туши** — под заголовками диалогов и групп настроек, у полок на главной,
  в разделителях меню, над подвалом магазина.
- **Шрифт заголовков** — Cinzel или Shippori Mincho (Google Fonts, OFL), кириллица
  из Cormorant SC и Cormorant.
- **Фоновое изображение** — ваша картинка с ползунками затемнения и размытия.
  Размытие 0 px — самый лёгкий вариант.

## Установка (Windows)

Нужен [Millennium](https://steambrew.app) 3.x (сверено по исходникам v3.6.3).

1. Распакуйте архив куда угодно.
2. Запустите `bleach-minimal-dark\install.bat`. Он найдёт Steam через реестр,
   скопирует тему в `<Steam>\millennium\themes\bleach-minimal-dark\` и уберёт
   лишнюю вложенную папку, если она осталась от ручной распаковки.
3. **Полностью закройте Steam** (Steam → Выход) и откройте снова.
4. Millennium → **Темы** → **Bleach Minimal Dark**.

Вручную: `skin.json` должен лежать сразу в
`<Steam>\millennium\themes\bleach-minimal-dark\`, а не во вложенной папке.

## Не работает? Проверьте по порядку

1. **Темы нет в списке** — проверьте путь до `skin.json` или запустите `install.bat`.
2. **Тема выбрана, но ничего не изменилось** — полностью перезапустите Steam.
3. **Всё равно ничего** — настройки Millennium → группа «Темы» → включите
   **«Разрешить внедрение CSS»** (англ. *Allow StyleSheet insertions*) и перезапустите Steam.
4. **После обновления Steam что-то снова стало синим или стоковым** — запустите
   `python tools\check_classes.py`. Он покажет классы, которые Valve поменяла
   (файл:строка). Затем `python tools\build_steam_palette.py` обновит страховочную
   перекраску. Нужен Python 3.8+, сторонние библиотеки не требуются; файлы Steam
   скачиваются с официального CDN Valve или берутся из своей установки через
   `--steamui "C:\Program Files (x86)\Steam\steamui"`.

## Как устроена тема

| Окно | Как распознаётся | Что грузится |
|---|---|---|
| Главное (библиотека, страница игры) | `.DesktopUI`, `^Steam$` | core + fallback + widgets + `main/*` |
| Друзья и чат | `.friendsui-container` | core + fallback + widgets + `friends/*` |
| Настройки и диалоги | `.ModalDialogPopup`, `.FullModalOverlay` | core + fallback + widgets + `settings/*` |
| Контекстные меню | `Menu$`, `Supernav$` | `core/tokens.css` + `widgets/menus.css` (10 КБ) |
| Магазин | `https://store\.steampowered\.com/.*` | `core/tokens.css` + `store/store.css` |

Big Picture не затрагивается: `UseDefaultPatches` выключен, стили главного окна
ограничены `body.DesktopUI`, страховочная перекраска пропускает `.GamepadMode` и `.BasicUI`.

**Цвета.** Все значения лежат в `colors.css` (RootColors, редактируются в Millennium).
`core/tokens.css` задаёт роли: полотно окна, глубокий слой, панели, выделение,
«клинок», линии хаори, свечение. Пресеты (`presets/*.css`) переназначают только
акцентные роли. В CSS-правилах нет ни одного цвета, записанного значением.

**Страховка** (`fallback/`). Для экранов, которые тема не оформляет вручную
(загрузки, коллекции, свойства игры, достижения), генератор переводит фоны и
синий акцент Steam на переменные темы. Он выдаёт только изменённые объявления и
никогда не перебивает ручные стили.

## Свой фон

1. Положите картинку в `assets/background.jpg`.
2. Вкладка **Фон** → «Клиент», «Клиент и друзья» или «Клиент, друзья и магазин».
3. Подберите **Затемнение** (75–85 % для светлых обоев) и **Размытие**.
4. Другое имя или формат указывается в строке `--bleach-bg-image` в `effects/background.css`.

## Что проверено, а что нет

Проверено:
- `skin.json` сверен с исходниками Millennium v3.6.3.
- Все 282 хэш-класса есть в CSS текущего Steam (client 1794536281).
- Макеты из настоящих классов Steam с настоящими `sp.css` и `library.css`
  (шапка и навигация, список игр, главная, панель «Играть», меню, настройки,
  друзья) отрисованы в Chromium в разных пресетах. Замеры производительности — выше.

**Не проверено:** тема не запускалась в живом клиенте Steam (у меня нет Windows и
вашего аккаунта), `install.bat` не выполнялся. Если что-то выглядит не так,
пришлите скриншот с подписью, где это: каждая область лежит в своём файле, и её
легко поправить точечно.

## Структура

```
bleach-minimal-dark/
├── install.bat / install.ps1   установщик для Windows
├── skin.json                   Patches, RootColors, Conditions (вкладки Пресет/Эффекты/Фон/Шрифт)
├── colors.css                  RootColors — все цвета темы
├── core/                       tokens.css (роли) · base.css (полотно, скроллбары, фокус)
├── widgets/                    controls (кнопки, поля, переключатели) · menus · dialogs
├── main/                       frame (шапка, навигация) · sidebar · home · details
├── friends/                    friends · chat
├── settings/                   settings (окна настроек Steam и Millennium)
├── store/                      store (магазин)
├── fallback/                   страховочная перекраска (генерируется)
├── presets/  effects/  fonts/  assets/  docs/
└── tools/                      check_classes.py · build_steam_palette.py
```

## Чек-лист

**Включить тему**
- [ ] Millennium 3.x установлен.
- [ ] Запущен `install.bat` (или `skin.json` лежит в `<Steam>\millennium\themes\bleach-minimal-dark\`).
- [ ] Steam полностью перезапущен → Millennium → **Темы** → **Bleach Minimal Dark**.

**Переключить пресет**
- [ ] Millennium → Темы → Bleach Minimal Dark → настройки → вкладка **Пресет**.
- [ ] «Пресет акцента»: Getsuga / Reiatsu / Hollow / Quincy / Свой.
- [ ] Для «Своего» поменяйте цвета «Свой · …» в редакторе цветов темы.
- [ ] Если не перекрасилось, перезапустите Steam.

**Добавить свой фон**
- [ ] Картинка лежит в `assets/background.jpg`.
- [ ] Вкладка **Фон** → «Фоновое изображение» не «Выкл».
- [ ] Затемнение и размытие подобраны так, чтобы текст читался.

**После обновления Steam**
- [ ] `python tools\check_classes.py` — всё на месте?
- [ ] Если нет: пришлите вывод (или поправьте классы), затем
      `python tools\build_steam_palette.py` и `install.bat`.
