# assets

Положите сюда свои обои под именем **`background.jpg`**, затем включите
«Фоновое изображение» во вкладке **Фон** настроек темы.

- Подойдёт любое разрешение; лучше всего от 1920×1080.
- Другое имя или формат: поменяйте строку `--bleach-bg-image` в `../effects/background.css`.
- Тема намеренно не содержит изображений.
