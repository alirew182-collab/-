# Minimal Dark · Bleach — надстройка для Minimal Dark (Millennium)

Это **Minimal Dark** от **SaiyajinK** без единого изменения в его вёрстке, плюс
слой **Bleach** поверх него:

- **Цвета Bleach для всего Minimal Dark:** Getsuga (алый), Reiatsu (голубой),
  Hollow (красный и костяной белый), Quincy (холодный бело-голубой) или его
  собственный цвет.
- **Ваши Bleach-арты вместо обложек игр** в библиотеке. Они идут по кругу, а при
  наведении видна настоящая обложка; можно оставить только арт.
- **Арт в шапке страницы игры** вместо широкой картинки игры (логотип игры остаётся).
- **Фон библиотеки:** затемнённые обои за полками и арт внизу левой колонки.
- **Иероглифы-водяные знаки:** 卍解 на главной, 死神 в левой колонке, 斬魄刀 на странице игры.
- **Эффекты:** reiatsu-свечение, shunpo-анимация карточек, мазки туши.

Всё включается и выключается на отдельной вкладке **«Bleach»** в настройках темы.
Все остальные настройки Minimal Dark (142 штуки) на месте и работают как обычно.

## Почему надстройка, а не копия

У Minimal Dark нет лицензии, значит все права у автора, и копировать его код в
другую тему или выкладывать его нельзя. Поэтому здесь **нет ни строчки Minimal Dark**.
Установщик берёт **ваш** экземпляр (архив с GitHub или уже установленную тему) и
у вас на компьютере делает из него отдельную тему «Minimal Dark · Bleach». Ваш
оригинальный Minimal Dark не меняется.

Поддержать автора Minimal Dark: <https://ko-fi.com/saiyajink>.
Сам Minimal Dark: <https://github.com/SaiyajinK/Minimal-Dark-for-Steam>.

## Картинки

Арты из аниме защищены авторским правом, поэтому в надстройке их нет: вы кладёте
свои. Подробности — в `bleach/assets/README.md`.

| Файл | Где появится |
|---|---|
| `bleach/assets/covers/*.jpg` (любое количество, лучше 600×900) | вместо обложек игр, по кругу |
| `bleach/assets/hero.jpg` (широкий) | шапка страницы игры |
| `bleach/assets/background.jpg` | фон главной библиотеки |
| `bleach/assets/sidebar.jpg` (вертикальный) | низ левой колонки |

Если какой-то картинки нет, соответствующая часть просто не меняется: пустых
обложек не будет. Поддерживаются jpg, png, webp, gif, avif.

## Установка (Windows)

1. Нужен [Millennium](https://steambrew.app) 3.x.
2. Положите архив Minimal Dark (`Minimal-Dark-for-Steam-6.6.8.zip`) рядом с
   `install.bat` или в папку «Загрузки». Можно и без архива, если Minimal Dark уже
   установлен в Millennium.
3. Положите свои арты в `bleach/assets/` (см. выше).
4. Запустите **`install.bat`**. Он:
   - найдёт Steam и ваш Minimal Dark;
   - создаст тему `<Steam>\millennium\themes\minimal-dark-bleach\`;
   - добавит слой Bleach и вкладку «Bleach» в настройки;
   - сгенерирует CSS под ваши картинки;
   - уберёт из копии ссылку на GitHub Minimal Dark, чтобы встроенное
     «обновление» не стёрло слой Bleach.
5. Полностью закройте Steam (Steam → Выход) и откройте снова.
6. Millennium → **Темы** → **Minimal Dark · Bleach** → настройки → вкладка **Bleach**.

**Добавили или поменяли картинки** — запустите `install.bat` ещё раз.
**Вышла новая версия Minimal Dark** — скачайте её архив и снова запустите `install.bat`.

Параметры для особых случаев:
`install.bat -Source "D:\архивы\Minimal-Dark-for-Steam-6.6.8.zip" -SteamPath "D:\Games\Steam"`.

## Настройки на вкладке «Bleach»

| Настройка | Варианты |
|---|---|
| Bleach · Цвет | **Getsuga** · Reiatsu · Hollow · Quincy · Как в Minimal Dark |
| Bleach · Обложки игр | **С обложкой при наведении** · Только арт · Обычные |
| Bleach · Шапка страницы игры | **Bleach-арт** · Обычная |
| Bleach · Фон библиотеки | **Вкл** · Выкл |
| Bleach · Иероглифы | **Вкл** · Выкл |
| Bleach · Reiatsu-свечение | **Вкл** · Выкл |
| Bleach · Shunpo | **Вкл** · Выкл (+ ползунок скорости 120–180 мс) |
| Bleach · Мазки туши | **Вкл** · Выкл |

Жирным выделены значения по умолчанию.

## Как это устроено

- Minimal Dark берёт весь акцент из системного цвета Millennium
  (`--SystemAccentColor`, а в магазине `--SystemAccentColorAccent`) и своих
  `--minimal_dark_color*`. Пресеты Bleach переопределяют только эти переменные,
  поэтому меняется цвет, а вёрстка Minimal Dark остаётся прежней.
- Обложки заменяются CSS-свойством `content` у картинки обложки
  (`appportrait_Image`). Картинки раздаются по порядку карточек в полке или сетке;
  при наведении включается `content: normal`, то есть настоящая обложка.
- Все хэш-классы Steam в надстройке (30) сверены с CSS текущего клиента
  (Steam client 1794536281).

## Что проверено, а что нет

Проверено в Chromium на макете из настоящих классов Steam с настоящим CSS Steam,
CSS Minimal Dark 6.6.8 (со всеми его настройками по умолчанию) и слоем Bleach,
в порядке подключения Millennium:
- пресеты перекрашивают Minimal Dark;
- арты идут по кругу, а при наведении видна настоящая обложка;
- шапка страницы игры заменяется;
- фон, арт колонки и иероглифы рисуются;
- объединённый `skin.json` корректен (151 настройка).

**Не проверено:** `install.bat` не запускался (здесь нет Windows) — его шаги
повторены на Python. В живом Steam надстройка не запускалась. Если что-то не так,
пришлите скриншот и вывод `install.bat`.
