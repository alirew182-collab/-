# Ваши Bleach-арты

Тема не содержит картинок — положите сюда свои (jpg, png, webp, gif, avif)
и запустите `install.bat` ещё раз: он создаст CSS только под те файлы, что
реально лежат здесь, поэтому пустых обложек не будет.

| Куда | Что | Где появится |
|---|---|---|
| `covers/` | сколько угодно вертикальных артов (лучше 600×900, 2:3), например `01.jpg`, `02.jpg`… | вместо обложек игр в библиотеке, по кругу в порядке имён |
| `hero.jpg` | широкий арт (лучше 1920×620 и шире) | шапка страницы игры |
| `background.jpg` | обои (1920×1080 и больше) | фон главной библиотеки, под затемнением |
| `sidebar.jpg` | вертикальный арт | низ левой колонки со списком игр |

Режим обложек меняется в настройках темы, вкладка «Bleach»: «С обложкой при
наведении» (арт, а при наведении — настоящая обложка), «Только арт» или «Обычные».
