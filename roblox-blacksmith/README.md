# System Blacksmith для Roblox (этапы 1–3)

Игра в жанре «кузнец + прокачка по Системе». Код на Luau (`--!strict`), проект на Rojo.
Вся игровая логика работает на сервере, клиент только рисует интерфейс и шлёт запросы.

Быстрый тест без Rojo: открой `build/SystemBlacksmith.rbxlx` в Studio и нажми Play.
Пересобрать файл после изменений кода: `python3 tools/build_rbxlx.py`.

## 0. Что нового в Этапе 3: обмен и лавки

Обмен между игроками. Подойди к игроку, нажми «Обмен» (T на ПК). Он получает приглашение на 20 секунд.
В окне обмена слева твоё оружие (нажатие добавляет или убирает его из предложения) и золото, справа то, что отдаёт другой игрок, с настоящими характеристиками.
«Готов» у обоих → через 3 секунды можно нажать «Подтвердить обмен». Любое изменение предложения сбрасывает готовность у обоих, а сервер принимает подтверждение только для той версии предложения, которую игрок видел. Так нельзя подменить меч в последнюю секунду.

Лавки. В Торговом ряду 16 прилавков, каждый игрок на сервере получает свой (имя на вывеске, 3 самых дорогих предмета на витрине).
Выставлять можно откуда угодно: Инвентарь → «Моя лавка». Покупатель подходит к прилавку → «Лавка» → выбирает предмет и подтверждает покупку вторым нажатием.
Рынок берёт 5% комиссии. Выставленное оружие нельзя надеть, продать торговцу или отдать в обмен.
Пока владелец не в игре, NPC-покупатели скупают до 6 предметов за 8 часов и платят не больше 1,5× цены у торговца.

Защита от дюпа: передача идёт на сервере одним блоком без пауз, у предмета сохраняется его Id, оба профиля сохраняются сразу после сделки, каждая сделка пишется в журнал (Output и DataStore `MarketLog_v1`).
Настройки: `Config/Trading.luau`.

### Управление по устройствам

| Действие | Телефон | ПК | Геймпад / консоль |
|---|---|---|---|
| Атака | кнопка «Атака» (удержание включает автоатаку) | ЛКМ | R2 |
| Блок / парирование | кнопка «Блок» | F | L2 |
| Действие (добыть, ковать, торговать, войти во Врата) | подсказка на экране | E | X |
| Инвентарь | кнопка справа | I | Y |
| Меню | кнопка справа | M | ↑ (крестовина) |
| Закрыть окно | крестик | крестик | B |
| Мини-игра ковки | большая кнопка | пробел / кнопка | A |

На ПК и геймпаде большие сенсорные кнопки скрываются, внизу экрана появляется подсказка управления.
Интерфейс сам переключается при смене устройства ввода (например, подключили геймпад к ПК).

## Проверка кода без Studio

`bash tools/checks/run_all.sh` прогоняет статические проверки за пару секунд:
парность блоков, порядок объявлений, циклические `require`, ключи локализации EN/RU, имена Remote,
ссылки между конфигами (мобы во Вратах, руда в наградах, события заданий) и сверку с Roblox API:
классы в `Instance.new`, сервисы, `Enum`, свойства и методы объектов. Определения API скачиваются из luau-lsp при первом запуске.
Поведение в игре (физика, вид мира, сеть) эти проверки не заменяют, его видно только в Studio.

## 1. Установка и подключение к Studio

### Инструменты (один раз)
1. Поставь Rokit (менеджер инструментов): https://github.com/rojo-rbx/rokit, по инструкции из его README.
2. В папке `roblox-blacksmith/` выполни:
   ```bash
   rokit install        # поставит rojo 7.4.4, selene, stylua из rokit.toml
   ```
   Без Rokit: скачай `rojo` 7.4.x со страницы релизов https://github.com/rojo-rbx/rojo/releases.
3. Плагин Rojo для Studio: `rojo plugin install` (или Creator Store → «Rojo»).
4. Удобно: VS Code + расширения Rojo и Luau Language Server (подсказки типов Roblox).

### Запуск
1. Открой в Studio новый плейс (шаблон **Baseplate**).
2. В терминале, в папке `roblox-blacksmith/`:
   ```bash
   rojo serve
   ```
3. В Studio: вкладка **Plugins → Rojo → Connect**. Код появится в
   `ReplicatedStorage/Shared`, `ServerScriptService/Server`, `StarterPlayer/StarterPlayerScripts/Client`.
4. Нажми **Play**. Если в карте нет своих объектов с тегом `OreNode`, сервер сам построит весь мир
   (папка `Workspace/World` + Terrain, ~1–3 секунды при старте). Шаблонные `Baseplate` и `SpawnLocation` при этом убираются.
   Отключить автопостройку: `Config/World.luau → AutoBuild = false` (тогда пустая карта получит минимальные блоки-заглушки).

Собрать файл плейса без Studio: `rojo build -o SystemBlacksmith.rbxlx`.

### Настройки плейса (Game Settings)
- Security → Enable Studio Access to API Services: включи, чтобы сохранение работало в Studio.
- **Workspace → StreamingEnabled = true** (Rojo ставит сам; проверь).
- **Avatar**: подойдут и R15, и R6 (оружие крепится к `RightHand` или `Right Arm`).

## 2. ProfileStore: сохранение данных, нужно до публикации

1. Скачай `ProfileStore.luau` с https://github.com/MadStudioRoblox/ProfileStore (раздел Releases / `src`).
2. В Studio создай **ModuleScript** в `ServerStorage`, назови `ProfileStore`, вставь код.
3. Всё. `DataService` найдёт его сам.

Если модуля нет, в Output будет предупреждение и включится `FallbackStore`, и **данные не сохраняются**
(только для быстрого теста). Защита от дюпа: ProfileStore блокирует сессию (один профиль = один сервер),
у каждого предмета уникальный GUID, предмет сначала удаляется и только потом начисляется золото.
Схема данных лежит в `src/server/Data/Template.luau`, версия и миграции в `src/server/Data/Migrations.luau`.

## 4. Карта: какие объекты поставить (теги через CollectionService)

Тег ставится в Studio: выдели объект, затем Properties → Tags → +. Атрибуты добавляются там же: Attributes → +.
Можно ставить и на `Part`, и на `Model` (у модели задай `PrimaryPart`).

| Что | Тег | Атрибуты | Заметки |
|---|---|---|---|
| Жила руды | `OreNode` | `OreId` (string): `Copper` / `Iron` / `Moonsilver`; `AutoStyle` (bool, необязательно) | По умолчанию перекрашивается в цвет руды. `AutoStyle = false` оставляет твою модель как есть |
| Наковальня/кузня | `Forge` | — | Поставь у модели `ModelStreamingMode = Persistent`, чтобы луч обучения видел её издалека |
| Торговец (NPC) | `Merchant` | — | Тоже `ModelStreamingMode = Persistent` |
| Точка появления Врат | `GateSpawn` | — | Невидимый Part на земле; портал появится на 6 studs выше. Поставь 2–4 точки |

Необязательные шаблоны (без них работают заглушки):

| Где | Имя | Требования |
|---|---|---|
| `ServerStorage/WeaponModels/` | `Sword`, `Axe`, `Spear` | Model или Part. Можно добавить `Attachment` с именем `Grip`: за него оружие берётся в руку |
| `ServerStorage/Mobs/` | `Ashling`, `CinderHound`, `CinderWarden` | Model с `Humanoid` и `HumanoidRootPart` (без скриптов) |
| `ServerStorage/Arenas/` | `GateArena` | Model; внутри Part с именами `PlayerSpawn` (2–4 шт.) и `MobSpawn` (4–8 шт.). Ставится далеко от лобби автоматически |

Как только в карте появится хотя бы один объект с каждым тегом, тестовые заглушки перестанут создаваться.

## 6. Как менять баланс и добавлять контент (без кода)

- **Новая руда:** запись в `Config/Ores.luau` + ключи `ORE_<ID>` и `MAT_<ID>` в `Localization/Strings.luau` (EN и RU) + Part с тегом `OreNode` и `OreId`.
- **Новый тип оружия:** запись в `Config/Weapons.luau` + ключ `WPN_<ID>`.
- **Новый моб/босс:** `Config/Mobs.luau` + ключ `MOB_<ID>`.
- **Новые Врата:** запись в `Config/Gates.luau → Types` + ключ `GATE_<ID>`.
- Цены, опыт, шансы и таймеры меняются числами в `Config/*`.

## 7. Чек-лист: что проверить в Studio (Этап 1)

**Запуск**
- [ ] Output: `[SystemBlacksmith] сервер запущен`, без красных ошибок.
- [ ] Через ~2 с появляется окно Системы «Ты пробудил класс: Кузнец (Ранг F)», затем квест «Добудь медную руду».
- [ ] Слева сверху ранг F, уровень, полоса опыта, золото; под ними трекер квеста с заголовком «[Система]»; синий луч ведёт к медной жиле.
- [ ] Кнопка EN/RU переключает язык всего интерфейса и подсказок (подсказки обновятся при следующем показе).

**Первые 60 секунд**
- [ ] Жми «Добыть» на медной жиле: искры, жила тускнеет после разрушения, тост «+N Медная руда», жила возвращается через 8 с.
- [ ] Квест → «Выкуй первое оружие», луч ведёт к наковальне.
- [ ] Кузня: выбрать Меч + Медь → КОВАТЬ → 3 шага (меха / заливка / молот). Пробел на ПК работает как кнопка, персонаж не прыгает.
- [ ] Окно Системы «Выковано: …», качество %, карточка результата, кнопка «Надеть». Меч появился в руке.
- [ ] На квесте «Надень оружие» у кнопки «Инвентарь» появляется рамка цвета углей.
- [ ] Торговец: вкладки Оружие / Руда / Кирки. Продажа требует второго нажатия. Надетое продать нельзя.

**Уровни и экономия**
- [ ] При повышении уровня появляется окно «[Система] · Новый уровень» с прибавкой здоровья и урона.
- [ ] Железо требует ур. 3 и железную кирку, без них появляются ошибки «Нужен уровень 3» / «Кирка слишком слабая».
- [ ] `leaderstats` (Level, Gold) видны в списке игроков.

**Врата**
- [ ] В Studio первый портал через ~5 с (на сервере через 25 с), объявление «Открылись Врата».
- [ ] «Войти во Врата» → карточка группы сверху, отсчёт 20 с, лидер может нажать «Начать».
- [ ] Перенос на арену, 2 волны, затем босс (окно «ОПАСНОСТЬ»), полоса HP босса.
- [ ] Перед ударом над мобом появляется «!». Блок (кнопка или F) снижает урон, а нажатие блока прямо перед ударом даёт «Парирование» и оглушает моба.
- [ ] Босс делает удар по площади с красным кругом, из которого можно выбежать.
- [ ] Победа: окно «ВРАТА ЗАЧИЩЕНЫ», золото, опыт, руда; через 6 с возврат к месту портала.
- [ ] Поражение (умереть всем) → «ПРОВАЛ», возврат.
- [ ] **Test → Clients and Servers → 2 игрока**: оба в одной группе, HP мобов выше, бонус опыта группы.

**Сохранение** (с ProfileStore и включённым API Access)
- [ ] После перезахода уровень, золото, руда, оружие, надетое оружие, язык и прогресс квестов на месте.

**Телефон** (Studio → Test → Device Emulator, например iPhone 14 в альбомной ориентации)
- [ ] Кнопки «Атака»/«Блок» не перекрывают прыжок, «Инвентарь» не мешает стику.
- [ ] Окна помещаются на экран, текст читается.

## 7б. Чек-лист Этапа 2

- [ ] При старте в Output: `[World] мир построен за N с`. Город, дороги к 4 зонам, горы по краям, озеро.
- [ ] Вход в зону показывает баннер с названием и рекомендуемым уровнем.
- [ ] В Медных холмах бродят слизи с подписью «Ур.1 Тлеющая слизь», отходят домой, если убежать, и восстанавливают HP.
- [ ] Через ~2 минуты в Карьере появляется Каменный колосс (окно «ЭЛИТНЫЙ МОНСТР» у всех).
- [ ] Кузня → «Шансы»: таблица шансов редкостей. Результат ковки показывает редкость и черты. При Legendary и выше появляется столб света.
- [ ] При Mythic и выше объявление видят все игроки на сервере (для проверки временно подними `Weight` у Mythic в `Config/Rarities.luau`).
- [ ] Черта «Огонь» поджигает моба (оранжевые цифры), «Крит» показывает «Крит N», «Вампиризм» лечит.
- [ ] На ур. 5 появляется окно «[Система] · Новый ранг», буква на значке меняется на E.
- [ ] Меню → Задания: 3 задания и серия входов; трекер слева после обучения ведёт к цели задания.

## 8. Известные недоделки (план на следующие этапы)

- Дальше: пробуждение оружия, скрытые классы, Испытания ранга с боссом, монетизация (геймпассы, продукты с идемпотентным `ProcessReceipt`), перерождение.
- Нет анимаций и звуков по умолчанию (нужны ID), портал и мобы пока заглушки.
- Мини-игру ковки невозможно сделать полностью защищённой от читов (замеры идут с клиента). Сервер ограничивает вред: случайные параметры каждой сессии, проверка реального времени, качество влияет на урон лишь ×0.7–×1.3, серии идеальных ковок пишутся в лог.
- Жила общая для сервера: руду получает тот, кто нанёс последний удар.
- Мёртвые во Вратах возрождаются в лобби, но награду при победе группы получают.
- Портал одноразовый: после старта забега он исчезает (следующий появится по таймеру).
- Купить в лавке можно только у игрока на том же сервере. Межсерверный рынок (аукцион) потребует MemoryStore и отдельной защиты, это следующий шаг.
- Окно риска дюпа при падении сервера сведено к минимуму немедленным сохранением обоих профилей, но полностью его закрывает только запись обеих сторон одной транзакцией, а у Roblox такой нет. Журнал сделок позволяет разобрать каждый случай.
- Открытие другого окна (инвентарь, меню) во время обмена отменяет обмен.
- Мобы открытого мира появляются только в автопостроенном мире (на своей карте включи `MobsOnCustomMap = true`, если координаты зон совпадают).
- Лидерборды обновляются раз в 2 минуты и записывают результат при выходе и раз в 5 минут.

## 8б. Стиль мира: стад-стиль (Studify)

Мир построен по правилам скилла Studify (RoClicks), без Terrain:
- все детали из пластика с узором шипов; узор по роли: `Universal` для земли и массивов, `StudsNoGrid` для крыш и травяных шапок, `Weld` для столбов, рам и ящиков, `Studs` для стен;
- пастель: салатовая трава, лососевая земля, лавандовый камень, бирюзовая вода; зимний рескин в Гроте;
- ступенчатые формы: круглые площадки собраны из полос, крыши — из уменьшающихся рядов, деревья — воксельные «блобы» на коралловых стволах, ели — ярусами;
- неон только как акцент на важном для игры: горн, руда лунного серебра, кромки площадок Врат, Кристалл Системы, фонари;
- по краю карты кольцо плато из ярусных масс с травяными шапками, без щелей;
- каждая деталь чуть больше заданного размера (до 0.02), поэтому грани соседей не совпадают и не мерцают.

Как сделать рендер сильнее: добавь в MaterialService варианты материала `Universal`, `StudsNoGrid`, `Weld`, `Studs` (Plastic), и мир сам начнёт их использовать. Шахматный оттенок травы: укажи `CheckerTextureId` в `Config/World.luau`.
Общий код деталей: `src/server/World/Stud.luau`, генератор: `src/server/World/WorldBuilder.luau`.

## 8в. Подключить Claude к Roblox Studio (MCP)

MCP-серверы работают рядом с запущенным Studio на твоём компьютере, из облака их не подключить. Варианты:
- Встроенный MCP-сервер Roblox Studio: официальный путь, см. https://create.roblox.com/docs/studio/mcp. Старый `Roblox/studio-rust-mcp-server` больше не развивается и сам советует встроенный.
- `boshyxd/robloxstudio-mcp`: поставь плагин из релизов репозитория в папку Plugins, затем в терминале
  `claude mcp add robloxstudio -- npx -y robloxstudio-mcp@latest`. Плагин покажет «Connected».

С подключённым MCP Claude Code на твоём компьютере сможет запускать Play, читать Output, делать скриншоты и править мир прямо в Studio: это закроет визуальную проверку, которую нельзя сделать в облаке.

## 9. Направление дизайна

Интерфейс приведён к единому направлению по правилам скилла [unslop](https://github.com/heydamir/unslop) Дамира Соколовского (CC BY 4.0), тексты отредактированы по правилам [no-ai-slop](https://github.com/petergyang/no-ai-slop).

- Мир: ночная кузня. Окна и кнопки в тёплом тёмном графите с тонкими линиями, без неона и градиентов.
- Главное действие (Ковать, Надеть, Продать, Атака) окрашено цветом углей, остальные кнопки нейтральные.
- Холодный синий свет есть только у Системы: окно Системы и заголовок «[Система]» в трекере задания.
- Шрифт Gotham весом 400 и 500, иерархия строится размером и цветом. Регистр предложений, без восклицательных знаков.
- Отступы на сетке 4px. Одна кривая анимации (ease-out), без пружин и бесконечного мигания.
- Все цвета лежат в `src/client/UI/Theme.luau`, менять их нужно только там.
