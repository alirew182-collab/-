# ⚒️ System Blacksmith — Roblox (Этапы 1–2)

Игра в жанре «кузнец + прокачка по Системе». Код на Luau (`--!strict`), проект на **Rojo**.
Вся игровая логика — на сервере; клиент только рисует интерфейс и шлёт запросы.

**Быстрый тест без Rojo:** открой `build/SystemBlacksmith.rbxlx` в Studio и нажми Play.
Пересобрать файл после изменений кода: `python3 tools/build_rbxlx.py`.

## 0. Что нового в Этапе 2

| Что | Где настраивать |
|---|---|
| **Полный мир кодом**: Terrain, город «Угольный Оплот» (кузня, лавка, фонтан с Кристаллом Системы, доски лидеров, фонари), Медные холмы, Карьер Железный Клык, Грот лунного серебра, Равнина Врат, озеро, горы-граница, освещение | `Config/World.luau` |

| **Адаптивность**: телефон / ПК / геймпад / консоль, масштаб пересчитывается при повороте и изменении окна | — |

### Управление по устройствам

| Действие | Телефон | ПК | Геймпад / консоль |
|---|---|---|---|
| Атака | кнопка «Атака» (удерживать — автоатака) | ЛКМ | R2 |
| Блок / парирование | кнопка «Блок» | F | L2 |
| Действие (добыть, ковать, торговать, войти во Врата) | подсказка на экране | E | X |
| Инвентарь | кнопка справа | I | Y |
| Меню | кнопка справа | M | ↑ (крестовина) |
| Закрыть окно | крестик | крестик | B |
| Мини-игра ковки | большая кнопка | пробел / кнопка | A |

На ПК и геймпаде большие сенсорные кнопки скрываются, внизу экрана появляется подсказка управления.
Интерфейс сам переключается при смене устройства ввода (например, подключили геймпад к ПК).

## 1. Установка и подключение к Studio

### Инструменты (один раз)
1. Поставь **Rokit** (менеджер инструментов): https://github.com/rojo-rbx/rokit — по инструкции из README.
2. В папке `roblox-blacksmith/` выполни:
   ```bash
   rokit install        # поставит rojo 7.4.4, selene, stylua из rokit.toml
   ```
   Без Rokit: скачай `rojo` 7.4.x со страницы релизов https://github.com/rojo-rbx/rojo/releases.
3. Плагин Rojo для Studio: `rojo plugin install` (или Creator Store → «Rojo»).
4. Удобно: VS Code + расширения **Rojo** и **Luau Language Server** (подсказки типов Roblox).

### Запуск
1. Открой в Studio новый плейс (шаблон **Baseplate**).
2. В терминале, в папке `roblox-blacksmith/`:
   ```bash
   rojo serve
   ```
3. В Studio: вкладка **Plugins → Rojo → Connect**. Код появится в
   `ReplicatedStorage/Shared`, `ServerScriptService/Server`, `StarterPlayer/StarterPlayerScripts/Client`.
4. Нажми **Play**. Если в карте нет своих объектов с тегом `OreNode`, сервер **сам построит весь мир**
   (папка `Workspace/World` + Terrain, ~1–3 секунды при старте). Шаблонные `Baseplate` и `SpawnLocation` при этом убираются.
   Отключить автопостройку: `Config/World.luau → AutoBuild = false` (тогда пустая карта получит минимальные блоки-заглушки).

Собрать файл плейса без Studio: `rojo build -o SystemBlacksmith.rbxlx`.

### Настройки плейса (Game Settings)
- **Security → Enable Studio Access to API Services** — включи, чтобы сохранение работало в Studio.
- **Workspace → StreamingEnabled = true** (Rojo ставит сам; проверь).
- **Avatar**: подойдут и R15, и R6 (оружие крепится к `RightHand` или `Right Arm`).

## 2. ProfileStore (сохранение данных) — обязательно перед публикацией

1. Скачай `ProfileStore.luau` с https://github.com/MadStudioRoblox/ProfileStore (раздел Releases / `src`).
2. В Studio создай **ModuleScript** в `ServerStorage`, назови `ProfileStore`, вставь код.
3. Всё. `DataService` найдёт его сам.

Если модуля нет, в Output будет предупреждение и включится `FallbackStore` — **данные не сохраняются**
(только для быстрого теста). Защита от дюпа: ProfileStore блокирует сессию (один профиль = один сервер),
у каждого предмета уникальный GUID, предмет сначала удаляется и только потом начисляется золото.
Схема данных — `src/server/Data/Template.luau`, версия + миграции — `src/server/Data/Migrations.luau`.

## 4. Карта: какие объекты поставить (теги через CollectionService)

Тег ставится в Studio: выдели объект → **Properties → Tags → +**. Атрибуты — там же, **Attributes → +**.
Можно ставить и на `Part`, и на `Model` (у модели задай `PrimaryPart`).

| Что | Тег | Атрибуты | Заметки |
|---|---|---|---|
| Жила руды | `OreNode` | `OreId` (string): `Copper` / `Iron` / `Moonsilver`; `AutoStyle` (bool, необязательно) | По умолчанию перекрашивается в цвет руды. `AutoStyle = false` — оставить твою модель как есть |
| Наковальня/кузня | `Forge` | — | Поставь у модели `ModelStreamingMode = Persistent`, чтобы луч обучения видел её издалека |
| Торговец (NPC) | `Merchant` | — | Тоже `ModelStreamingMode = Persistent` |
| Точка появления Врат | `GateSpawn` | — | Невидимый Part на земле; портал появится на 6 studs выше. Поставь 2–4 точки |

Необязательные шаблоны (если нет — используются заглушки):

| Где | Имя | Требования |
|---|---|---|
| `ServerStorage/WeaponModels/` | `Sword`, `Axe`, `Spear` | Model или Part. Можно добавить `Attachment` с именем `Grip` — за него оружие берётся в руку |
| `ServerStorage/Mobs/` | `Ashling`, `CinderHound`, `CinderWarden` | Model с `Humanoid` и `HumanoidRootPart` (без скриптов) |
| `ServerStorage/Arenas/` | `GateArena` | Model; внутри Part с именами `PlayerSpawn` (2–4 шт.) и `MobSpawn` (4–8 шт.). Ставится далеко от лобби автоматически |

Как только в карте появится хотя бы один объект с каждым тегом, тестовые заглушки перестанут создаваться.

## 6. Как менять баланс и добавлять контент (без кода)

- **Новая руда:** запись в `Config/Ores.luau` + ключи `ORE_<ID>` и `MAT_<ID>` в `Localization/Strings.luau` (EN и RU) + Part с тегом `OreNode` и `OreId`.
- **Новый тип оружия:** запись в `Config/Weapons.luau` + ключ `WPN_<ID>`.
- **Новый моб/босс:** `Config/Mobs.luau` + ключ `MOB_<ID>`.
- **Новые Врата:** запись в `Config/Gates.luau → Types` + ключ `GATE_<ID>`.
- **Цены, опыт, шансы, таймеры** — меняй числа в `Config/*`.

## 7. Чек-лист: что проверить в Studio (Этап 1)

**Запуск**
- [ ] Output: `[SystemBlacksmith] сервер запущен`, без красных ошибок.
- [ ] Через ~2 с — окно Системы «Ты пробудил класс: Кузнец (Ранг F)», затем квест «Добудь медную руду».
- [ ] Слева сверху ранг F, уровень, полоса опыта, золото; под ними — трекер квеста; золотой луч ведёт к медной жиле.
- [ ] Кнопка EN/RU переключает язык всего интерфейса и подсказок (подсказки обновятся при следующем показе).

**Первые 60 секунд**
- [ ] Жми «Добыть» на медной жиле: искры, жила тускнеет после разрушения, тост «+N Медная руда», жила возвращается через 8 с.
- [ ] Квест → «Выкуй первое оружие», луч ведёт к наковальне.
- [ ] Кузня: выбрать Меч + Медь → КОВАТЬ → 3 шага (меха / заливка / молот). Пробел на ПК работает как кнопка, персонаж не прыгает.
- [ ] Окно Системы «Выковано: …», качество %, карточка результата, кнопка «Надеть». Меч появился в руке.
- [ ] Квест «Надень оружие» — пульсирует кнопка «Инвентарь».
- [ ] Торговец: вкладки Оружие / Руда / Кирки. Продажа требует второго нажатия. Надетое продать нельзя.

**Уровни и экономия**
- [ ] Повышение уровня — окно «УРОВЕНЬ ПОВЫШЕН», HP растёт (видно по полоске здоровья Roblox).
- [ ] Железо требует ур. 3 и железную кирку — без них ошибки «Нужен уровень 3» / «Кирка слишком слабая».
- [ ] `leaderstats` (Level, Gold) видны в списке игроков.

**Врата**
- [ ] В Studio первый портал через ~5 с (на сервере — 25 с), объявление «Открылись Врата».
- [ ] «Войти во Врата» → карточка группы сверху, отсчёт 20 с, лидер может нажать «Начать».
- [ ] Перенос на арену, 2 волны, затем босс (окно «ОПАСНОСТЬ»), полоса HP босса.
- [ ] Мобы краснеют перед ударом. Блок (кнопка/F) снижает урон; нажатие блока прямо перед ударом — «ПАРИРОВАНИЕ!» и оглушение моба.
- [ ] Босс делает удар по площади с красным кругом — из круга можно выбежать.
- [ ] Победа: окно «ВРАТА ЗАЧИЩЕНЫ», золото, опыт, руда; через 6 с возврат к месту портала.
- [ ] Поражение (умереть всем) → «ПРОВАЛ», возврат.
- [ ] **Test → Clients and Servers → 2 игрока**: оба в одной группе, HP мобов выше, бонус опыта группы.

**Сохранение** (с ProfileStore и включённым API Access)
- [ ] Выйти/зайти — уровень, золото, руда, оружие, надетое оружие, язык и прогресс квестов на месте.

**Телефон** (Studio → Test → Device Emulator, например iPhone 14 в альбомной ориентации)
- [ ] Кнопки «Атака»/«Блок» не перекрывают прыжок, «Инвентарь» не мешает стику.
- [ ] Окна помещаются на экран, текст читается.

## 7б. Чек-лист Этапа 2

- [ ] При старте в Output: `[World] мир построен за N с`. Город, дороги к 4 зонам, горы по краям, озеро.
- [ ] Вход в зону показывает баннер с названием и рекомендуемым уровнем.
- [ ] В Медных холмах бродят слизи с подписью «Ур.1 Тлеющая слизь», отходят домой, если убежать, и восстанавливают HP.
- [ ] Через ~2 минуты в Карьере появляется Каменный колосс (окно «ЭЛИТНЫЙ МОНСТР» у всех).
- [ ] Кузня → «Шансы»: таблица шансов редкостей. Результат ковки показывает редкость и черты. Legendary+ — столб света.
- [ ] Mythic+ — объявление у всех игроков на сервере (для проверки временно подними `Weight` у Mythic в `Config/Rarities.luau`).
- [ ] Черта «Огонь» поджигает моба (оранжевые цифры), «Крит» — «КРИТ N!», «Вампиризм» лечит.
- [ ] На ур. 5 — окно «НОВЫЙ РАНГ: E», буква на значке меняется.
- [ ] Меню → Задания: 3 задания и серия входов; трекер слева после обучения ведёт к цели задания.
- [ ] Меню → Коды: `RELEASE` даёт награду, повторно — «Код уже использован».
- [ ] Меню → Настройки: выключение звука, цифр урона, «слабая графика» (пропадают эффекты свечения и тени).
- [ ] Доски лидеров в городе заполняются (нужен опубликованный плейс и API Services).
- [ ] Красные врата: красный портал и объявление (для проверки подними `RedGate.Chance`).
- [ ] Геймпад: Y открывает инвентарь, B закрывает, выделение кнопок работает; на ПК — I и M.
- [ ] Device Emulator в портретной ориентации: окна помещаются по ширине.

## 8. Известные недоделки (план на следующие этапы)

- **Этап 3**: торговля между игроками, лавки игроков, пробуждение оружия, скрытые классы, Испытания ранга с боссом, монетизация (геймпассы, продукты с идемпотентным `ProcessReceipt`), перерождение.
- Нет анимаций и звуков по умолчанию (нужны ID), портал и мобы — заглушки.
- Мини-игру ковки невозможно сделать полностью защищённой от читов (замеры идут с клиента). Сервер ограничивает вред: случайные параметры каждой сессии, проверка реального времени, качество влияет на урон лишь ×0.7–×1.3, серии идеальных ковок пишутся в лог.
- Жила общая для сервера: руду получает тот, кто нанёс последний удар.
- Мёртвые во Вратах возрождаются в лобби, но награду при победе группы получают.
- Интерфейс масштабируется при запуске; при повороте экрана/изменении окна во время игры размер не пересчитывается.
- Портал одноразовый: после старта забега он исчезает (следующий — по таймеру).
- Мобы открытого мира появляются только в автопостроенном мире (на своей карте — `MobsOnCustomMap = true`, если координаты зон совпадают).
- Подсказки ProximityPrompt переводятся при следующем показе, а не мгновенно при смене языка.
- Лидерборды обновляются раз в 2 минуты и записывают результат при выходе и раз в 5 минут.
